# 2025 建築師考古題模擬系統

以單機靜態網頁製作的 2025（民國 114 年）建築師考試練習工具，包含：

- 營建法規與實務：80 題
- 建築結構：40 題選擇題、2 題申論題
- 每科 120 分鐘倒數、作答對錯判定、例子說明與剩餘題數
- 考選部試題 PDF 檢視連結，供查閱原卷圖示與公式選項

## 在本機使用

下載 `index.html` 與 `questions.js` 至同一資料夾，使用瀏覽器開啟 `index.html`。官方原卷 PDF 檢視需要網路連線。

## 發布到 GitHub Pages

1. 將本專案檔案推送到 GitHub 儲存庫的根目錄。
2. 到儲存庫 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等待 GitHub Pages 完成部署，網址格式為 `https://<GitHub帳號>.github.io/<儲存庫名稱>/`。

題目與答案依考選部 114 年建築師考試公開試題整理。引用或轉載時請保留來源及考選部原始公告：
